# HeartSync 戀愛教練模擬器 (PWA)

這是一個專為戀愛聊天練習、性格盲點分析打造的 Progressive Web App (PWA)。

## 🌟 核心特色
1. **個人盲點雷達**：輸入八字日主、MBTI 與星座，即時診斷「理性講理、木訥、缺乏推拉」等對話盲點。
2. **客製化對象人設**：自由輸入心儀女生的八字性格、星座、生活圈與地雷話題。
3. **沉浸式實戰模擬**：
   - 內建智能回覆引擎（免輸入 API Key 即刻可用）。
   - 支援串接 Google Gemini API 達成 100% 擬真人格回覆。
   - 心理潛台詞透視（看清女生心裡真正想法）。
   - 盲點警告條（在輸入框前即時提醒直男死穴）。
4. **PWA 原生體驗**：支援 iOS / Android 「加入主畫面」，全螢幕操作，支援離線快取。

## 🚀 3 步免費部署到 GitHub Pages

1. **建立 GitHub Repository**
   - 登入 [GitHub](https://github.com/)，點擊右上角 `New repository`。
   - Repository 名稱填寫 `heartsync`（建議設為 Public）。
   - 點擊 `Create repository`。

2. **上傳此專案所有檔案**
   - 將解壓縮後的目錄中所有檔案（包含 `index.html`、`manifest.json`、`sw.js` 以及 `icons/` 資料夾）直接拖曳上傳至該 Repository。
   - 點擊綠色 `Commit changes` 按鈕保存。

3. **啟用 GitHub Pages**
   - 進入該 Repository 的 **Settings** > 側邊欄點選 **Pages**。
   - 在 **Build and deployment** 下方的 Branch 選擇 `main`（或 `master`），資料夾選擇 `/(root)`。
   - 點擊 **Save**。
   - 等待約 1 分鐘，上方會出現專屬網址（例如：`https://你的帳號.github.io/heartsync/`）。

打開手機 Safari / Chrome 瀏覽該網址，點選「分享」>「加入主畫面」，即可當作原生手機 App 隨時隨地練習！
